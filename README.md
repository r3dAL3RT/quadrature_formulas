# Численное интегрирование и оценка погрешностей

Скрипт на Python для вычисления определенных интегралов (включая интегралы с особенностями) различными численными методами, оценки порядка сходимости по Эйткену и уточнения решений по Ричардсону.

## Реализованные методы

1. **Классические квадратурные формулы:**
   * Метод левых прямоугольников
   * Метод средних прямоугольников
   * Метод трапеций
   * Метод Симпсона

2. **Квадратурные формулы для интегралов с особенностями вида $\int_a^b \frac{f(x)}{(x-a)^\alpha} dx$:**
   * Метод Ньютона-Котеса (с интегральными моментами)
   * Квадратура типа Гаусса (с решением системы для моментов и корней через формулу Кардано)

## Оценка точности и сходимости

* **Процесс Эйткена:** Автоматическое вычисление эффективного порядка сходимости $m$ на трех сетках.
* **Экстраполяция Ричардсона:** Двукратное уточнение полученных значений интеграла.
* **Автоматический выбор шага:** Поиск количества разбиений $N$, обеспечивающего заданную точность $\varepsilon = 10^{-6}$.

## Зависимости

* Python 3.x
* `numpy`
* `scipy`
* `matplotlib`

## Использование

Запуск вычислений и генерация графиков погрешностей:

```bash
python ALLsteps.py
```

При запуске скрипт:
1. Выводит в консоль результаты интегрирования и погрешности по Ричардсону.
2. Сохраняет графики зависимости погрешности от количества разбиений:
   * `abs_error_f4.png` — для классических методов.
   * `abs_error_l2.png` — для методов Ньютона-Котеса и Гаусса.
